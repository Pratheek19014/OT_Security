Use UAExpert like this (short steps):

Create file

In Address Space, right‑click Objects → Programs (FileDirectoryType) → Call Method → CreateFile.
Input: fileName = myfile.nc
Result: NodeId of the new File object.
Open the new file (write)

In Address Space, add the returned NodeId (right‑click → Add Node / Custom Node).
Right‑click the new File object → Call Method → Open.
Input: mode = 6 (Write + EraseExisting) or 2 (Write).
Result: handle (UInt32).
Write data

Right‑click the same File object → Call Method → Write.
Input: handle = <returned handle>, data = ByteString (UAExpert lets you paste hex/base64).
Close

Call Close with the same handle.

ByteString = "Hello" -> 0x48656C6C6F0A

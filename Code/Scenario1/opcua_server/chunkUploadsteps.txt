UAExpert Workflow
1. Connect to the Server
Open UAExpert
Add Server: opc.tcp://localhost:4840
Connect to the server
2. Navigate to the File Object
In the Address Space, expand:
Objects → Programs → GCode_Job1
You should see:
Variables: Size, Writable, UserWritable, OpenCount, Checksum
Methods: Open, WriteHex, Close
3. Open the File
Right-click on the Open method → Call
Input Arguments:
mode (Byte): Enter 1 (write mode)
Click Call
Note the returned fileHandle (e.g., 1) - you'll need this for the next steps
4. Write Hex Data (Multiple Times)
Right-click on the WriteHex method → Call
Input Arguments:
file_handle (UInt32): Enter the handle from step 3 (e.g., 1)
hex_data (String): Paste your hex string chunk
Example: 47303020583020593020 (represents "G0 X0 Y0 ")
Click Call
Verify the return status is Good
Repeat for each chunk of your hex-encoded file
5. Close the File
Right-click on the Close method → Call
Input Arguments:
file_handle (UInt32): Enter the same handle (e.g., 1)
Click Call
The file will be written to C:/shares/program01/GCode_Job1.gcode
6. Verify the Upload
Check the updated variables:
Size: Should show the file size in bytes
Checksum: Should show the SHA256 hash
Check the file on disk at: C:/shares/program01/GCode_Job1.gcode
